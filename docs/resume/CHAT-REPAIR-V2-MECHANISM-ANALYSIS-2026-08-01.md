# Alpha chat repair v2 — failure-mechanism analysis

**Analysis date:** 2026-08-01

**Status:** diagnostic complete; repair v2 remains rejected

**GPU activity:** none

**Public model:** unchanged; quality gate remains `FAIL`

**Sealed-final evaluation:** not executed or inspected

## Executive conclusion

Repair v2 did not fail because its supervised answers were full of the loops that Alpha later emitted. It failed
because ordinary teacher-forced likelihood training did not teach Alpha how to remain stable under its own
generated history.

On the exact 69 development prompts that the published baseline and every v2 checkpoint could all generate:

- every v2 checkpoint fixed the baseline's one empty response;
- every v2 checkpoint also created 11–17 new loop flags while fixing only 4–7 old ones;
- loops usually began after only about 18–24 generated tokens;
- 28 previously non-looping prompts became loops in at least one v2 checkpoint;
- five previously non-looping prompts became loops in every v2 checkpoint;
- only one baseline loop was fixed by every v2 checkpoint;
- almost none of the supervised targets were themselves repetitive;
- no candidate produced a statistically reliable embedding-based semantic-contingency gain over baseline.

The best-supported mechanism is therefore a **self-amplifying autoregressive attractor**: a plausible early token
choice moves the model into a prefix distribution it did not see under teacher forcing; repeated local patterns
then become increasingly probable and the model cannot recover. Extra clean maximum-likelihood training changes
which prompts enter those attractors, but does not remove the underlying preference.

This is not proof that data quality is irrelevant. It is evidence that another unmodified clean-SFT continuation
is not a sufficient intervention.

## Question this analysis answers

Repair v2 established a puzzling combination:

1. the training corpus passed strong structural and repetition audits;
2. validation loss improved;
3. answer initiation became reliable;
4. free generation became more repetitive and was not more useful.

The purpose of this analysis was to distinguish among four explanations before spending more GPU time:

1. the training targets contain hidden repetitive or copied patterns;
2. the model memorizes exact answers or dominant answer openings;
3. the new checkpoints improve relevance but are unfairly rejected by a crude repetition metric;
4. the objective behaves well on gold prefixes but poorly on prefixes generated by the model itself.

The evidence most strongly supports explanation 4.

## Analysis instruments

### Exact transition analyzer

`scripts/analyze_chat_repair_transitions.ts` joins every eligible prompt by immutable ID and reports:

- structural, nonempty, EOS, role-leak, and loop status;
- transition from baseline for every candidate;
- the first repeated generated 4-gram position;
- last-user/output lexical overlap;
- exact supervised-target matches;
- source and prompt-length strata;
- supervised-target repetition, copying, length, and answer-start concentration;
- whether dominant generated loop phrases occur in the training answers.

An initial all-96 run exposed the placeholder-row denominator error. That invalid diagnostic was preserved as
`transition-analysis-all96-v0.*`; it was not overwritten or silently repaired. The eligible-69 result is the
scientific comparison.

### Semantic-contingency analyzer

`scripts/analyze_chat_repair_semantic_alignment.py` uses `BAAI/bge-small-en-v1.5` to compare each preserved
response with:

- its actual final user turn;
- all unrelated final user turns;
- the held-out source response.

It evaluates one fixed population: the 68 eligible prompts for which all nine runs are nonempty. It reports paired
cosines, prompt-retrieval rank, output/reference cosine, source strata, and paired bootstrap intervals against
baseline.

This instrument is a supporting diagnostic, not a quality judge. Embedding similarity cannot establish truth,
valid reasoning, naturalness, or whether an answer actually helps. Its calibration is nevertheless useful: the
held-out source responses retrieve their own prompts top-1 in 58/68 cases with MRR 0.8916.

## What the training-target audit found

The rendered v2 training data contains 23,529 conversations and 68,964 assistant targets.

| Audit | Result |
|---|---:|
| Assistant target word length, q25 / median / q75 | 17 / 55 / 119 |
| Targets with word-4-gram repeat rate at least 0.2 | 3 / 68,964 |
| Targets with last-user/output Jaccard at least 0.6 | 353 / 68,964 |
| Distinct normalized exact targets | 67,876 |
| Largest exact four-word answer opening count | 119 |

Across the dominant phrases found in generated loops:

- 214 distinct dominant phrases were audited;
- 110 did not occur in any supervised target;
- those absent phrases account for 1,330 of 2,383 weighted generated dominant-phrase occurrences;
- 173 of 371 loop rows had a dominant phrase absent from all supervised targets;
- only 2–5 of the 69 model outputs per run exactly matched any normalized supervised answer.

This rules out a simple story in which Alpha is replaying many dirty loop examples verbatim. It does not rule
out compositional influence from ordinary phrases or more subtle distributional effects.

## Representative attractor transitions

These examples are not selected as the metric; they illustrate the transition counts above.

### St. Louis Cathedral

The baseline gives a short, flawed but terminating description. Pilot A and Pilot B repeat variants of
“we'll take a stroll through the square” until the completion cap. That dominant loop phrase occurs in none of
the 68,964 supervised targets.

### Pronic numbers

The baseline provides an incorrect explanation but terminates. Later checkpoints repeatedly emit “the first 5
numbers.” The intervention changed a bounded semantic failure into an unbounded one.

### Focus advice

The baseline asks an unhelpful question but stops. Later checkpoints repeat “the tasks you need to do” or “easy
to use.” The loop is not restricted to long prompts or factual tasks.

### Conceptual discussion of suicide

The baseline makes a relevant distinction involving self-awareness. Both v2 arms regress into repeated fragments
of the word and stock explanation. The failure occurs on the kind of conceptual language Alpha ultimately needs
to handle well.

## Hypotheses after analysis

| Hypothesis | Status | Evidence |
|---|---|---|
| Training answers directly contain the generated loops | **Strongly disfavored** | 3/68,964 targets cross the loop threshold; 110/214 dominant phrases are absent |
| Alpha mostly memorizes exact answers | **Disfavored** | only 2–5 exact target matches per run; 67,876 distinct targets |
| V2 is semantically better despite repetition | **Not supported** | all paired semantic bootstrap intervals cross zero |
| Answer-start weighting solved full conversation | **Rejected** | it fixed emptiness but new loops and stopping regressions dominated |
| More clean CE continuation will eventually fix v2 | **Rejected as the next experiment** | both continuation and clean-base controls moved the same failure around |
| Model-generated prefixes expose a likelihood-training blind spot | **Best-supported working hypothesis** | early new loops, clean targets, and checkpoint instability match this mechanism |

## Relation to primary research

[Welleck et al., *Neural Text Generation with Unlikelihood Training*](https://arxiv.org/abs/1908.04319)
show that maximum-likelihood models can assign excessive probability to repeats and introduce token- and
sequence-level unlikelihood training.

[Li et al., *Don't Say That!*](https://aclanthology.org/2020.acl-main.428/) extend unlikelihood to dialogue,
including within-utterance repetition, copying, frequent vocabulary, and collected undesirable continuations.

[He and Glass, *Negative Training for Neural Dialogue Response Generation*](https://aclanthology.org/2020.acl-main.185/)
identify undesirable outputs from a trained dialogue model and feed them back as negative signals.

[Guan and Huang, *Self-Contrastive Training*](https://aclanthology.org/2023.findings-acl.431/) report that models
learn simple repeated patterns early, penalize repetition behavior from a premature checkpoint, and find evidence
that repetitive tokens rely on longer-range dependencies than non-repetitive tokens.

[Cai et al., *Group-wise Contrastive Learning for Neural Dialogue Generation*](https://aclanthology.org/2020.findings-emnlp.70/)
provide adjacent evidence that dialogue models benefit when positive and negative responses are made explicit
rather than supplying positives alone.

These papers support the intervention class. They do not establish that it will work in Alpha's engine, corpus,
or current checkpoint. That remains the purpose of repair v3.

## Decision for repair v3

The next bounded experiment should change the objective, not the decoding policy or corpus topic distribution.
It should:

1. generate failure trajectories only from train-assigned prompts;
2. detect repeated continuation positions mechanically;
3. preserve the positive human/teacher response under ordinary CE;
4. apply unlikelihood only to tokens that complete an already-repeated assistant 4-gram;
5. compare against a matched zero-unlikelihood control;
6. use a new frozen selector for checkpoint choice;
7. use the eligible-69 v2 set only as a secondary regression panel;
8. leave the sealed-final suite closed unless the candidate passes development admission.

Repair v3 is specified in `docs/resume/CHAT-REPAIR-V3-EXPERIMENT-CONTRACT.md`.

## Epistemic limits

This analysis does not establish that:

- unlikelihood will make Alpha generally conversational;
- every repeated phrase is undesirable;
- the source responses are uniquely correct;
- embedding similarity is a sufficient quality metric;
- the current foundation can learn all desired conversational behavior;
- one objective repair removes parroting, shallow reasoning, and factual mistakes.

It establishes a narrower result: v2's remaining free-generation failure cannot be explained by repetitive
targets alone, appears under the model's own prefixes, and was not repaired by more clean likelihood training.
